# 引导互动

#### 17. 问一个紧贴主题的问题

- **怎么做**：问一个观众凭自己的经历就能回答的问题，把话头交给他；问题要接住这条的重点。
- **变体**：开放式提问、反问收尾、反问观众收尾、引导评论、邀请留言。
- **库中例子出现于**：短视频口播、公众号长文、通用；种草、教程、观点、带货、故事。各变体按当前内容选用，不把这个并集当作每种题材都适合的证明。
- **图什么**：获得相关回应。
- **素材里要有**：正文自然留下的可讨论问题。
- **别用在／风险**：不用每条都加“你怎么看”；不能突然问一个与主线无关的问题。
- **原文结尾**：“同学们想了解什么也可以在评论区留言我会选中大家问的比较多的在创作识锦囊中给大家解答”[[sources/community/xiaoe-8d11160ce80e0b4c]]
- **原文嵌套演示**：“那你会把家里的毛孩子送去读书吗”[[sources/community/xiaoe-22a1926cfb5700e6]]
- **来源数**：22（29 条）。

#### 18. 摆出具体选项，请观众选

- **怎么做**：把真实的两难或几个具体选项说清楚，让观众选一个并讲理由。
- **变体**：让观众站队、让观众出主意。
- **库中例子出现于**：通用、短视频口播；种草、故事、观点、评论。各变体按当前内容选用，不把这个并集当作每种题材都适合的证明。
- **图什么**：获得相关回应。
- **素材里要有**：确实存在的选项与选择条件。
- **别用在／风险**：不是强迫站队，不编造争议；只想要答案时别做无谓对立。
- **和相近写法的区别**：有明确选项才是选择题；没有现成选项时用第 17 或 20 种。
- **原文结尾**：“哪个选题你最想看，请在评论区写下你认为最好的选题”[[sources/community/xiaoe-4cbdf512a9366fdf]]
- **原文结尾**：“吃醋的孕妈淋着雨去停车场 这期视频你接受吗”[[sources/community/xiaoe-7b97a9eb8fbdb443]]
- **来源数**：9（14 条）。

#### 19. 请有同样经历的人接着说

- **怎么做**：说完自己的事，请遇到过类似情况的人补充经历；也可以留一句只有经历者懂的回应。
- **变体**：邀请分享经历、共鸣句收尾。
- **库中例子出现于**：短视频口播、通用、图文笔记；故事、观点、教程、评论、种草、带货、资讯。各变体按当前内容选用，不把这个并集当作每种题材都适合的证明。
- **图什么**：获得相关回应。
- **素材里要有**：这条已经讲具体的共同处境。
- **别用在／风险**：别把猜测当群体经历；不要求观众公开隐私。
- **原文结尾**：“你们都买在了哪里 我买了古滇 快来评论区聊聊吧”[[sources/community/zsxq-14425544551488452]]
- **原文结尾**：“现实生活中你们都是怎么熬过来的？”[[sources/community/zsxq-82258825224515452]]
- **来源数**：6（9 条）。

#### 20. 请观众帮忙、点评或试一试

- **怎么做**：给观众一个小而明确的参与动作：提个建议、点评一个作品，或按刚学的方法做个小尝试。
- **变体**：请观众帮个小忙、向观众求助、自己试完求点评、请观众点评、发起评论区挑战、请观众发来帮他改。
- **库中例子出现于**：短视频口播、公众号长文；教程、评论、故事。各变体按当前内容选用，不把这个并集当作每种题材都适合的证明。
- **图什么**：获得相关回应。
- **素材里要有**：能展示的对象，或你确实接得住的反馈。
- **别用在／风险**：要帮人改就说明能处理的范围；不把不可兑现的服务当互动诱饵。
- **原文结尾**：“但是兄弟们我真的觉得电子妆容 非常实用我也p了一张大家帮我点评一下（图片展示）”[[sources/community/zsxq-82258822885888282]]
- **原文结尾**：“如果是真的 那也太没底线了 有没有懂行的能帮我们解答一下”[[sources/community/zsxq-22258281445525581]]
- **来源数**：7（9 条）。

#### 21. 顺着已有约定提醒点赞

- **怎么做**：已经完成前面约定的挑战或给足价值时，简短提醒一个支持动作，随后结束。
- **变体**：引导点赞。
- **库中例子出现于**：短视频口播；故事、观点、教程。各变体按当前内容选用，不把这个并集当作每种题材都适合的证明。
- **图什么**：获得相关回应。
- **素材里要有**：这条实际完成的内容或前面说好的约定。
- **别用在／风险**：不把点赞当领取必要答案的交换条件。
- **原文结尾**：“老铁咋样？是不是也让全村都点到了？别忘了你的诺言啊！”[[sources/course/xuehui-322f262b8c5f52de]]
- **例子缺口**：这一轮只选到一条合适的台词或短句，不补编第二条。
- **来源数**：2（2 条）。
